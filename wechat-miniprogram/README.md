# StringArtHelper 微信小程序版

“绕线助手”的原生微信小程序版。免费、开源、纯本地运行，不使用云开发或业务服务器，并可与 Android 版互通项目存档和 TXT 钉号序列。

## 当前版本

`v1.2.1`

## 已实现

- 中英文界面，横竖屏自适应。
- 从相册或相机选择图片。
- 裁切预览与算法输入使用同一份灰阶图；支持圆形裁切、单指移动、双指缩放、完整图片放入圆内和圆外半透明遮罩。
- 图片外区域按白色板材处理。
- 钉子数、线条数、钉位圆、板材和线径参数。
- 线径范围 `0.01–1.00 mm`，结束输入时自动收口到最近边界。
- Worker 内纯本地绕线生成算法：预缓存可用弦像素，以平方误差下降选择下一根弦，并根据真实线径自动停止，避免重复覆盖导致全黑。
- 全序列预览、真实线径、预览线径、缩放、平移和生成动画。
- 前一个/当前/下一个钉号阅读器、手动换步、跳转和定时播放。
- 当前进度自动保存；支持自动续做项目、手动快照、重命名、覆盖和删除。
- 文件型项目存档及旧版本地数据迁移，减少微信本地存储容量占用。
- TXT 导入与导出，支持从文件名和文件内容读取钉数、线径与圆径元数据。
- 读取 UTF-8、UTF-8 BOM、UTF-16LE BOM 和 UTF-16BE BOM 文本。
- 导入 SAR2、SAR3、SAR4，以及使用相同二进制格式的 `.bin` 存档；以 SAR4 导出和分享项目。
- 与 Android 版双向传递完整钉号序列、当前进度、物理参数和缩略图。
- 按实际毫米尺寸生成钉位模板 PDF。
- 内置离线中英文真人数字语音，支持播报速度调节。
- 阅读器提供实时进度与完整动画组合预览，当前线段以 1.5 倍线宽紫色高亮。
- 独立的微信小程序版“关于”页，提供开源仓库、改进建议邮箱和安卓版 Bilibili 入口。

## 小程序平台限制

- 内置轻量中英文数字语音包，可在完全离线状态播报 0–99999 的钉号。
- 无法监听系统蓝牙耳机/媒体键。
- 文件分享和相册/相机选择需要在真机微信中完成，开发者工具只能覆盖模拟能力。
- 上传 TXT 或 BIN 文件时，需要先把文件转发到聊天，再从聊天文件中选择上传。
- 无网络不影响生成、预览、播报和存档；微信本身能否启动仍由微信平台与登录状态决定。
- 极高钉数会增加弦缓存占用和首次生成准备时间；生成过程仍完全位于本机 Worker 中。

## 导入开发者工具

在微信开发者工具中直接导入本目录。仓库内 `project.config.json` 使用正式小程序 AppID；仅查看和本地调试分支时，可按开发者工具提示改用测试号或自己的 AppID。个人设置保存在不会提交的 `project.private.config.json` 中。

## 本地测试

```bash
npm test
```

测试会依次执行四组检查：

- 原有核心回归测试；
- 生成算法、TXT、SAR 与裁切吸附测试；
- 文件型存档和旧数据迁移测试；
- 页面事件、中英文文案、文件入口提示及关键静态规则审计。

`v1.2.1` 的上述自动测试已全部通过。相册、相机、聊天文件选择、分享以及不同尺寸手机上的布局仍应在真机微信中核对。

## 项目结构

```text
pages/       页面与交互
utils/       TXT、SAR、PDF、存档、语音和通用逻辑
workers/     本地绕线生成算法
assets/      离线语音与应用资源
tests/       Node.js 自动测试
tools/       离线语音资源维护脚本
```
