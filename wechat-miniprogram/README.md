# StringArtHelper 微信小程序版

Android 原版“绕线助手”的原生微信小程序迁移版。免费、开源、纯本地运行，不使用云开发或业务服务器。

## 当前版本

`v1.1.3`（待下一次合并提交）

## 已实现

- 中英文界面，横竖屏自适应。
- 从相册或相机选择图片。
- 裁切预览与算法输入使用同一份灰阶图；支持圆形裁切、单指移动、双指缩放、完整图片放入圆内和圆外半透明遮罩。
- 图片外区域按白色板材处理。
- 钉子数、线条数、钉位圆、板材和线径参数。
- 线径范围 `0.01–1.00 mm`，结束输入时自动收口到最近边界。
- Worker 内纯本地绕线生成算法：预缓存可用弦像素，以平方误差下降选择下一根弦，并根据真实线径自动停止，避免重复覆盖导致全黑。
- 全序列预览、真实线径、预览线径、缩放、平移和生成动画。
- 前一个/当前/下一个钉号阅读器、手动换步、跳转和定时播放。
- 当前进度恢复、手动存档、重命名和删除。
- TXT 导入与导出。
- 按实际毫米尺寸生成钉位模板 PDF。
- 独立的微信小程序版“关于”页，提供改进建议邮箱和安卓版 Bilibili 入口。

## 小程序平台限制

- 内置轻量中英文数字语音包，可在完全离线状态播报 0–99999 的钉号。
- 无法监听系统蓝牙耳机/媒体键。
- 文件分享和相册/相机选择需要在真机微信中完成，开发者工具只能覆盖模拟能力。
- 极高钉数会增加弦缓存占用和首次生成准备时间；生成过程仍完全位于本机 Worker 中。

## 导入开发者工具

直接导入本目录。未配置正式 AppID 时使用 `touristappid` 进行本地开发；发布前在 `project.config.json` 中替换为注册的小程序 AppID。

## 本地测试

```text
node tests/core.test.js
```

测试覆盖 TXT 解析、细/粗线生成、路径范围和 PDF 文件结构。
