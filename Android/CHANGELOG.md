# 更新记录

本文件记录 Android 正式版的主要变化。完整提交历史请查看 GitHub 仓库。

## 26.5.9（versionCode 72）

- 中文钉号恢复正常数词读法，0～1000 均由应用生成标准中文文本，例如 119 读作“一百一十九”、171 读作“一百七十一”。
- 主页新增“快一点”和“慢一点”快捷按钮，每次将播报后的等待间隔缩短或延长 0.5 秒。
- 音量键功能与手环翻腕动作增加“快一点”“慢一点”选项，双端等待间隔保持同步。
- 配套手环端版本同步为 26.5.9。

## 26.5.8（versionCode 71）

- 修复 `.sar` 存档仍显示“导入”且导入后不会立即打开的问题。
- `.bin` 与 `.sar` 存档现在统一使用“导入并打开”；同名存档的保留与覆盖分支也会在导入后立即打开。

## 26.5.7（versionCode 70）

- 存档页面增加存档可同步至小米手环、脱离手机继续使用的提示。
- 中文钉号改为逐位交给 TTS，例如 119 读作“一一九”，不再按自然数单位播报。
- 配套手环端版本同步为 26.5.7。

## 26.5.6（versionCode 69）

- 对调“向外翻腕”和“向内翻腕”的显示文字，不改变既有手势映射逻辑。
- 手机端点击“下一步”并成功换步时，手环按设置执行长振动反馈。
- 配套手环端版本同步为 26.5.6。

## 26.5.5（versionCode 68）

- 修复手环跳转页永久停留在“正在读取手机或手环存档状态”。
- 主页打开跳转页时直接传递当前进度，实时通信只负责刷新和执行，不再阻塞页面。
- 区分手机连接通道与离线存档模式，保证两种来源都能正确跳转。
- 配套手环端版本同步为 26.5.5。

## 26.5.4（versionCode 67）

- 新增“找回钉号位置”：输入连续钉号后精确匹配，重复结果按距当前进度由近到远排列。
- 手机与手环跳转均提供 5 秒撤销窗口，可立即撤销或确认。
- 修复手环跳转状态未加载、指令无回执和跳转不振动。
- 手环离线存档支持独立定时播报推进与逐步振动。
- 配套手环端版本同步为 26.5.4。

## 26.5.3（versionCode 66）

- 手环在线状态优先于离线存档，未同步存档也持续显示手机当前钉号。
- 重构手环设置页、存档页与预览缩放，修复空白内容、无效按钮和放大偏移。
- 存档缩略图与进度预览增加长度及 CRC32 落盘校验。
- 配套手环端版本同步为 26.5.3。

## 26.5.2（versionCode 65）

- 短屏竖屏开启实时预览时，前一个、当前、下一个改为三列横排，避免钉号和跳转区被挤出屏幕。
- 改用 Android Adaptive Icon，正确适配圆形、圆角方形等桌面图标遮罩。
- 配套手环端版本统一为 26.5.2。

## 26.3.5（versionCode 61）

- `.bin` 存档导入确认操作改为“导入并打开”，导入成功后立即进入对应项目继续制作。
- 同名 `.bin` 存档的“保留两份”和“覆盖”分支同步支持导入后立即打开。
- “微信小程序版”菜单加入小程序码、完整入口口令和复制按钮。

## 26.3.4（versionCode 60）

- 主页新增预计剩余时间。
- 预计时间会结合剩余步骤、播报设置和实际制作节奏动态校准。
- 不足一分钟时显示“预计少于一分钟”；更长时间按分钟或“小时＋分钟”显示。
- 暂停、切换后台、后退和跳转不会污染速度统计。

## 26.3.3（versionCode 59）

- “关于”页新增 GitHub 开源仓库说明和可点击入口。
- README 新增微信小程序版、跨平台互通和隐私说明。

## 26.3.2（versionCode 58）

- 主页首次使用入口与顶部按钮统一改为“导入”。
- 导入时自动识别 TXT 钉号序列、`.bin` 项目存档，并继续兼容 `.sar` 存档。
- 不支持的文件格式会给出明确提示。

## 26.3.1（versionCode 57）

- “更多”页面加入微信小程序版入口；微信搜索“绕线画助手”即可使用。
- Android 版与微信小程序版支持通过项目存档和 TXT 序列跨平台继续制作。
- 调整主页按钮布局和文案，统一视觉样式。
- “反馈与联系”页新增作者原神 UID 的一键复制入口。
- 修复若干菜单布局与界面细节。
